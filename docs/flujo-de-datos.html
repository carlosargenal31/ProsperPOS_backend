🔄 Proceso Completo de una Petición

1
Usuario Interactúa
El usuario realiza una acción en la interfaz (ej: crear venta, buscar producto). Vue Router gestiona la navegación y Pinia actualiza el estado.
2
Petición HTTP
Axios envía una petición HTTP (GET, POST, PUT, DELETE) al backend con el token JWT en el header Authorization.
3
CORS y Seguridad
Express valida el origen de la petición (CORS), aplica headers de seguridad (Helmet) y verifica límites de peticiones.
4
Autenticación JWT
El middleware de autenticación verifica la firma del token JWT, valida su expiración y carga los datos del usuario en req.user.
5
Verificación de Permisos
El middleware de autorización verifica que el usuario tenga los permisos necesarios para ejecutar la acción solicitada (RBAC).
6
Validación de Datos
Express-validator o Joi validan los datos de entrada (req.body, req.params, req.query) contra esquemas predefinidos.
7
Controlador Procesa
El controlador correspondiente recibe la petición validada, extrae los parámetros y llama al servicio apropiado.
8
Servicio Ejecuta
El servicio aplica la lógica de negocio, valida reglas específicas, e interactúa con los modelos para acceder a los datos.
9
Transacción en BD
Los modelos ejecutan queries SQL parametrizadas. Las operaciones críticas se envuelven en transacciones para garantizar integridad.
10
Triggers Automáticos
Los triggers de MySQL actualizan automáticamente tablas relacionadas (ej: actualizar stock tras una venta).
11
Respuesta Formateada
El servicio retorna los datos al controlador, que los formatea en una respuesta JSON estandarizada con status y data/error.
12
Cliente Actualiza UI
Axios recibe la respuesta, actualiza el store de Pinia y Vue re-renderiza los componentes afectados de forma reactiva.
