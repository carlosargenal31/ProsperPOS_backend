🎭 Roles del Sistema
👑
Administrador
Acceso completo al sistema. Puede gestionar usuarios, configuraciones, y todos los módulos del sistema.

Permisos principales:

  • Gestión de usuarios y roles
  • Configuración del sistema
  • Acceso a todos los módulos
  • Reportes y auditoría
  • Configuración de sucursales
  • Gestión de permisos
👔
Gerente
Supervisa operaciones diarias, autoriza descuentos, gestiona inventario, genera reportes financieros y contables.

Permisos principales:

  • Autorizar descuentos especiales
  • Gestión de inventario
  • Reportes de ventas y compras
  • Gestión de proveedores
  • Devoluciones y notas de crédito
  • Reportes financieros y contables
  • Libro de compras y ventas
  • Exportar datos contables
  • Consultar facturas SAR
  • Estados de cuenta
🛍️
Vendedor
Procesa ventas, gestiona clientes, realiza cotizaciones, maneja caja y procesa pagos del punto de venta.

Permisos principales:

  • Crear y procesar ventas
  • Gestionar clientes
  • Crear cotizaciones
  • Consultar productos
  • Imprimir facturas
  • Procesar pagos
  • Apertura y cierre de caja
  • Registrar gastos de caja
  • Imprimir tickets
  • Devoluciones simples
📦
Almacenero
Gestiona inventario físico, traslados entre bodegas y ajustes de inventario.

Permisos principales:

  • Inventario físico
  • Ajustes de inventario
  • Traslados entre bodegas
  • Recepción de compras
  • Consultar stock
  • Reportes de inventario

💻 Implementación del Sistema

1. Middleware de Verificación de Permisos

// backend/src/middlewares/auth.middleware.js const checkPermission = (resource, action) => { return async (req, res, next) => { try { // El usuario ya fue validado por verifyToken() const userId = req.user.id; // Obtener permisos del usuario desde el token JWT const permissions = req.user.permissions || []; // Verificar si tiene el permiso requerido const hasPermission = permissions.some( p => p.resource === resource && p.action === action ); if (!hasPermission) { return res.status(403).json({ error: 'No tienes permisos para realizar esta acción' }); } next(); } catch (error) { res.status(500).json({ error: error.message }); } }; };

2. Uso en Rutas

// backend/src/routes/products.routes.js const express = require('express'); const router = express.Router(); const { verifyToken, checkPermission } = require('../middlewares/auth'); const productController = require('../controllers/product.controller'); // Todos necesitan estar autenticados router.use(verifyToken); // Consultar productos - Todos los roles autenticados router.get('/', checkPermission('products', 'read'), productController.getAll ); // Crear producto - Solo Admin y Gerente router.post('/', checkPermission('products', 'create'), productController.create ); // Actualizar producto - Solo Admin y Gerente router.put('/:id', checkPermission('products', 'update'), productController.update ); // Eliminar producto - Solo Admin router.delete('/:id', checkPermission('products', 'delete'), productController.delete );

3. Consulta de Permisos en el Login

// backend/src/services/auth.service.js const getUserWithPermissions = async (userId) => { const query = ` SELECT u.id, u.email, u.name, u.role_id, r.name as role_name, p.resource, p.action FROM users u INNER JOIN roles r ON u.role_id = r.id INNER JOIN role_permissions rp ON r.id = rp.role_id INNER JOIN permissions p ON rp.permission_id = p.id WHERE u.id = ? AND u.is_active = 1 `; const [rows] = await db.query(query, [userId]); // Agrupar permisos const user = { id: rows[0].id, email: rows[0].email, name: rows[0].name, role: rows[0].role_name, permissions: rows.map(r => ({ resource: r.resource, action: r.action })) }; return user; };
