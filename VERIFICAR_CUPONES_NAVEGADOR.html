🔍 Verificación de Cupones con Producto Específico

⚠️ Problema Reportado:
Cuando seleccionas un PRODUCTO ESPECÍFICO en un cupón, el sistema lo está aplicando a TODOS los productos de la misma categoría/subcategoría.

📋 Pasos de Verificación

1️⃣ Verificar Estructura de la Base de Datos

Abre tu gestor de base de datos (MySQL Workbench, phpMyAdmin, etc.) y ejecuta:

DESCRIBE coupons;

Busca este campo:

Field Type Null Default
articulo_id int YES NULL

✅ Si existe: Bien, continúa al paso 2

❌ Si NO existe: Ejecuta la migración SQL

2️⃣ Verificar Cupones Actuales

Ejecuta esta consulta para ver cómo están guardados tus cupones:

SELECT
  id,
  codigo,
  nombre,
  tipo_aplicacion,
  grupo_id AS categoria_id,
  subgrupo_id AS subcategoria_id,
  articulo_id AS producto_id
FROM coupons
WHERE deleted_at IS NULL
ORDER BY id DESC
LIMIT 10;

Interpreta los resultados:

codigo categoria_id subcategoria_id producto_id Estado
000007 1 5 NULL PROBLEMA
000008 1 5 123 CORRECTO
000009 1 NULL NULL OK (Categoría)

3️⃣ Crear Cupón de Prueba

Desde la interfaz web:

  1. Ve a Ventas → Cupones
  2. Haz clic en "Agregar Nuevo Cupón"
  3. Nombre: PRUEBA PRODUCTO ÚNICO
  4. Selecciona "Seleccionar una categoría y/o producto en específico"
  5. Selecciona una Categoría
  6. Selecciona una Subcategoría
  7. ⚠️ IMPORTANTE: Selecciona un Producto específico
  8. Tipo de Descuento: Monto
  9. Valor: 10.00
  10. Abre la Consola del navegador (F12)
  11. Haz clic en "Guardar"

4️⃣ Verificar en la Consola del Navegador

En la consola (F12), busca un log que diga:

Datos a enviar: {
  codigo: "000010",
  nombre: "PRUEBA PRODUCTO ÚNICO",
  tipo_aplicacion: "grupo",
  categoria_id: 1,
  subcategoria_id: 5,
  producto_id: 123,  ← ✅ DEBE TENER UN NÚMERO
  ...
}

Verificar:

  • ✅ Si producto_id tiene un número: El frontend está funcionando correctamente
  • ❌ Si producto_id: null: Hay un problema en el frontend

5️⃣ Verificar en Base de Datos

Ejecuta esta consulta con el código del cupón que acabas de crear:

SELECT
  codigo,
  nombre,
  grupo_id,
  subgrupo_id,
  articulo_id
FROM coupons
WHERE codigo = '000010'  -- Reemplaza con tu código
AND deleted_at IS NULL;
✅ Resultado Esperado:
articulo_id debe tener el ID del producto que seleccionaste, NO NULL.
❌ Si es NULL:
Hay un problema en el backend al guardar los datos.

6️⃣ Probar en el POS

  1. Ve al módulo POS
  2. Agrega al carrito 3 productos diferentes de la misma categoría/subcategoría
  3. Aplica el cupón que creaste
  4. Abre la consola del navegador (F12)
  5. Busca los logs que digan:
=== VALIDATE COUPON DEBUG ===
Cupón encontrado: {
  id: 10,
  codigo: '000010',
  tipo_aplicacion: 'grupo',
  grupo_id: 1,
  subgrupo_id: 5,
  articulo_id: 123  ← ✅ DEBE TENER VALOR
}
...
Items aplicables encontrados: 1  ← ✅ DEBE SER 1, NO 3

🔧 Solución Temporal (Mientras se investiga)

Alternativa que SÍ funciona:

  1. Al crear el cupón, selecciona "Seleccionar múltiples productos"
  2. Busca y agrega SOLO el producto al que quieres aplicar el descuento
  3. NO agregues otros productos
  4. Guarda el cupón

De esta manera, aunque uses tipo "multiple", el cupón solo se aplicará al producto que agregaste.
