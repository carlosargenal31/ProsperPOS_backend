🔍 Debug Sidebar Vendedor

ℹ️ Importante: Esta página te ayudará a identificar por qué el sidebar no aparece para el usuario vendedor.

Paso 1: Verificar que estás logueado

Primero, asegúrate de estar logueado en ProsperPOS como vendedor.

Paso 2: Verificar Roles del Usuario

Vamos a verificar qué roles tiene tu usuario en localStorage.

Paso 3: Ver Logs del Sidebar

⚠️ IMPORTANTE: Debes tener abierta la aplicación de ProsperPOS en otra pestaña como vendedor.

Los logs de depuración se están mostrando en la consola del navegador.

  1. Ve a la pestaña de ProsperPOS donde estás logueado como vendedor
  2. Presiona F12 para abrir las herramientas de desarrollo
  3. Ve a la pestaña Console
  4. Busca mensajes que comiencen con:
    • [canViewSection]
    • [canViewSubmenuItem]
    • FILTERING SIDEBAR FOR ROLES
    • FILTERED SIDEBAR RESULT

❌ Problemas Comunes y Soluciones

Problema 1: "FILTERING SIDEBAR FOR ROLES: []" (array vacío)

Causa: El usuario no tiene roles asignados.

Solución:

  1. Cierra sesión
  2. Asegúrate de que el backend esté corriendo
  3. Inicia sesión de nuevo

Problema 2: "FILTERING SIDEBAR FOR ROLES: ["Vendedor"]" (nombre en lugar de slug)

Causa: El backend está enviando nombres de roles en lugar de slugs.

Solución:

  1. Reinicia el backend
  2. Cierra sesión
  3. Inicia sesión de nuevo

Problema 3: "Total sections: 0"

Causa: Ninguna sección pasó el filtro.

Diagnóstico: Busca en los logs las líneas [canViewSection] para ver por qué todas están en FALSE.

Posibles causas:

  • Roles incorrectos (ver Problema 1 y 2)
  • El archivo sidebar-permissions.js no se cargó correctamente
  • Los nombres de las secciones no coinciden exactamente

Problema 4: Secciones correctas pero sin menús (0 menus)

Causa: Los submenús están siendo filtrados completamente.

Diagnóstico: Busca líneas [canViewSubmenuItem] para ver qué está pasando con cada item.

Ejemplo de log esperado:

[canViewSubmenuItem] "Ventas" > "Archivos" > "Cupones": Cashier - true - submenuItems: ["Cupones", "Ofertas"] [canViewSubmenuItem] "Ventas" > "Archivos" > "Ofertas": Cashier - true - submenuItems: ["Cupones", "Ofertas"]

🔧 Herramientas de Diagnóstico

Ejecutar Diagnóstico Completo

Ejecuta este código en la consola de la pestaña de ProsperPOS (F12 → Console):

// Diagnóstico completo del sidebar const user = JSON.parse(localStorage.getItem('user')); console.log('=== DIAGNÓSTICO COMPLETO ==='); console.log(''); console.log('1. Usuario:', user?.username); console.log('2. Roles:', user?.roles); console.log('3. Tipo de roles:', typeof user?.roles); console.log('4. Es array?:', Array.isArray(user?.roles)); console.log(''); if (user?.roles) { console.log('Verificando permisos de cada rol:'); user.roles.forEach(role => { console.log(` - Rol: "${role}"`); console.log(` Es cashier?: ${role === 'cashier'}`); console.log(` Es warehouse?: ${role === 'warehouse'}`); console.log(` Es admin?: ${role === 'admin'}`); }); } else { console.error('❌ No hay roles en el usuario!'); } console.log(''); console.log('=== FIN DIAGNÓSTICO ===');

📞 Checklist de Verificación

  • Backend está corriendo en http://localhost:3000
  • Frontend está corriendo en http://localhost:3001
  • Caché del navegador limpiado (Ctrl + Shift + R)
  • Sesión cerrada y reiniciada
  • Iniciado sesión con usuario vendedor
  • Usuario tiene roles: ["cashier"]
  • Logs aparecen en consola (F12)
  • Logs muestran "Total sections: 5" o similar
  • Cada sección tiene al menos 1 menu
  • Sidebar es visible en la interfaz
✅ Si todos los checkboxes están marcados:
El sidebar debería estar funcionando. Si aún no aparece, puede ser un problema de CSS o del componente Vue que no está renderizando correctamente.
⚠️ Si algún checkbox NO está marcado:
Corrige ese problema primero antes de continuar. Usa los logs de la consola para identificar exactamente dónde está fallando.
