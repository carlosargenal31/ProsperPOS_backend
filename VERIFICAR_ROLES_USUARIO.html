🔍 Verificar Roles de Usuario en ProsperPOS

Paso 1: Abrir la Consola del Navegador

Presiona F12 en tu navegador para abrir las herramientas de desarrollo.

Paso 2: Copiar y Ejecutar el Siguiente Código

Copia este código y pégalo en la consola:

// Verificar roles de usuario en localStorage const userStr = localStorage.getItem('user'); console.log('=== VERIFICACIÓN DE ROLES ==='); console.log(''); console.log('1. Usuario en localStorage (raw):', userStr); console.log(''); if (!userStr) { console.error('❌ ERROR: No hay usuario en localStorage'); console.log('Debes iniciar sesión primero'); } else { try { const user = JSON.parse(userStr); console.log('2. Usuario parseado:', user); console.log(''); console.log('3. Roles del usuario:', user.roles); console.log(''); // Verificar tipo de roles if (user.roles && Array.isArray(user.roles)) { console.log('✅ user.roles es un array'); console.log('Cantidad de roles:', user.roles.length); console.log(''); user.roles.forEach((role, index) => { console.log(` Rol ${index + 1}: "${role}" (tipo: ${typeof role})`); }); console.log(''); // Verificar qué rol es if (user.roles.includes('admin') || user.roles.includes('super_admin')) { console.log('👑 Usuario es ADMINISTRADOR'); console.log('Debería ver: Manual Administrador'); } else if (user.roles.includes('cashier')) { console.log('💰 Usuario es VENDEDOR'); console.log('Debería ver: Manual Vendedor'); } else if (user.roles.includes('warehouse')) { console.log('📦 Usuario es BODEGA'); console.log('Debería ver: Manual Bodega'); } else { console.log('⚠️ Rol no reconocido:', user.roles); console.log(''); console.log('PROBLEMA: El rol debería ser uno de estos slugs:'); console.log(' - admin'); console.log(' - super_admin'); console.log(' - cashier'); console.log(' - warehouse'); } } else { console.error('❌ ERROR: user.roles NO es un array o no existe'); console.log('user.roles:', user.roles); } // Verificar permisos console.log(''); console.log('4. Permisos del usuario:', user.permissions); } catch (error) { console.error('❌ ERROR al parsear el usuario:', error); } } console.log(''); console.log('=== FIN DE VERIFICACIÓN ===');

¿Qué Hacer Si Hay Problemas?

Problema 1: Roles son nombres en lugar de slugs

Ejemplo: roles: ["Vendedor"] en lugar de roles: ["cashier"]

Solución:

  1. Cierra sesión
  2. Reinicia el backend
  3. Inicia sesión de nuevo

Problema 2: No hay usuario en localStorage

Solución:

  1. Inicia sesión en el sistema
  2. Vuelve a ejecutar esta prueba

Problema 3: Roles es null o undefined

Solución:

  1. Verifica que el backend esté funcionando
  2. Cierra sesión y vuelve a iniciar sesión
