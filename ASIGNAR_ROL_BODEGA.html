🏭 Asignar Rol de Bodega a Usuario

📋 Información:

Esta herramienta te ayudará a asignar el rol de Personal de Bodega a un usuario existente.

El rol incluye 25 permisos para gestionar inventario completamente.

Si no conoces el ID, haz clic en "Buscar Usuarios" abajo

📝 SQL Manual

⚠️ Importante: Ejecuta estos comandos en tu base de datos si prefieres hacerlo manualmente.

1. Buscar usuarios disponibles

SELECT id, username, email FROM users ORDER BY id;

2. Asignar rol de bodega al usuario

-- Reemplaza USER_ID con el ID del usuario
INSERT INTO user_roles (user_id, role_id, created_at)
VALUES (USER_ID, 12, NOW());

3. Actualizar permisos del usuario

-- Reemplaza USER_ID con el ID del usuario
UPDATE users
SET permissions = '["products.read","products.create","products.update","products.delete","products.import","products.export","categories.read","categories.create","categories.update","categories.delete","brands.read","brands.create","brands.update","brands.delete","inventory.read","inventory.adjust","inventory.transfer","inventory.count","inventory.movements","reports.inventory","reports.export","shipments.read","shipments.create","shipments.delete","dashboard.view"]'
WHERE id = USER_ID;

4. Verificar asignación

-- Reemplaza USER_ID con el ID del usuario
SELECT u.id, u.username, u.email, r.name as role
FROM users u
JOIN user_roles ur ON u.id = ur.user_id
JOIN roles r ON ur.role_id = r.id
WHERE u.id = USER_ID;

✅ Pasos Finales

  1. Ejecuta el SQL generado en tu base de datos
  2. El usuario debe cerrar sesión
  3. El usuario debe iniciar sesión nuevamente
  4. Será redirigido automáticamente a /inventory/product-list
  5. El botón POS no será visible
