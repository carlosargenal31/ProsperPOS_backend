Sidebar de Vendedor - Listo para Probar

🔧 Cambios Aplicados

  • ✅ Eliminada sección "Gestión de Usuarios"
  • ✅ "Cerrar Sesión" movido a Ajustes → Ajustes Generales
  • ✅ Corregida expansión de submenús (Archivos, Procesos, Reportes)
  • ✅ Mantenida reactividad de Vue para clicks
  • ✅ Filtrado de permisos por rol vendedor

🚀 Pasos para Probar

1
Limpiar Caché del Navegador

Esto es CRÍTICO para ver los cambios:

Ctrl + Shift + R o Ctrl + Shift + Supr → Borrar caché
2
Cerrar Sesión y Volver a Iniciar

Para cargar los nuevos permisos:

3
Iniciar Sesión como Vendedor

Usa las credenciales del usuario vendedor

4
Verificar el Sidebar

Debes ver las siguientes secciones:

  • ✓ Ventas
  • ✓ Inventario
  • ✓ Ajustes
  • ✓ Ayuda
⚠️ NO debe aparecer:
  • ❌ Gestión de Usuarios (eliminada)
5
Probar Expansión de Submenús

Haz clic en "Ventas" y verifica que se expandan:

  • Archivos: Debería mostrar Cupones, Ofertas
  • Procesos: Debería mostrar POS Facturación, Devoluciones Ventas, Guías de Remisión
  • Reportes: Debería mostrar Reimpresiones Ventas, Ventas por Vendedor, Estado Cuenta Ventas
6
Verificar "Cerrar Sesión"

En el sidebar, ve a:

Ajustes → Ajustes Generales → Cerrar Sesión
✅ Ahora "Cerrar Sesión" está dentro de "Ajustes Generales" en lugar de estar en su propia sección
7
Probar POS Invoice

Abre el POS y verifica que cargue sin errores 403:

✅ Deberían cargar correctamente:
  • Bodegas (warehouses)
  • Resoluciones activas
  • Cuentas bancarias
  • Categorías
  • Tasas de impuesto

🎯 Resultado Esperado

✅ Si Todo Funciona Correctamente:

  • ✅ El sidebar muestra solo: Ventas, Inventario, Ajustes, Ayuda
  • ✅ NO aparece "Gestión de Usuarios"
  • ✅ "Cerrar Sesión" está en Ajustes → Ajustes Generales (al final)
  • ✅ Al hacer clic en "Archivos" (Ventas), se expande y muestra opciones
  • ✅ Al hacer clic en "Procesos" (Ventas), se expande y muestra opciones
  • ✅ Al hacer clic en "Reportes" (Ventas), se expande y muestra opciones
  • ✅ POS carga sin errores 403
  • ✅ Todos los datos del POS se cargan correctamente

⚠️ Si Algo No Funciona:

  1. Abre la Consola del Navegador (F12)
  2. Ve a la pestaña "Console"
  3. Busca mensajes de error (en rojo)
  4. Copia los errores y repórtalos
